\# SMK Backend Project



Project dasar koneksi PHP ke database MySQL untuk Seleksi Member TEFA.



\## Persyaratan

\- Laragon (Apache \& MySQL)

\- PHP 8.x

\- MySQL / MariaDB



\## Cara Menjalankan

1\. Pindahkan folder ke `C:\\laragon\\www\\`.

2\. Import/Jalankan file `database.sql` ke MySQL.

3\. Buka browser dan akses `http://localhost/smk-backend/`.
